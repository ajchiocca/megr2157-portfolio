# A11 team website package

Open index.html to view the report. It includes all figures and viewable copies of the drawings.

For the MEGR 2157 MkDocs portfolio, place mkdocs/index.md as
docs/assignments/a11/index.md, then copy the images and files folders beside it.
The existing A11 navigation entry can point to that index.md.

For another website, use report.md or index.html and preserve the relative
images/ and files/ paths. The named sections are the shared team content.

files/A11-team-report.pdf contains the report, the six original CAD drawings,
and the source BOM sheets from A10 and A11.
